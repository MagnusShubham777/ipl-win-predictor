# Data / attribution note

This implementation is an independent project. The original CampusX IPL win-probability repository should not be copied or presented as original work.

For training data, use a dataset whose terms permit your use. Cricsheet provides IPL match data in JSON/YAML and experimental CSV formats. See https://cricsheet.org/downloads/.

For live score ingestion, use a provider whose API license permits your application. Do not scrape a website or ship provider credentials in the frontend.
